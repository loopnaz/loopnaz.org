# _data/

This directory contains [global data](https://www.11ty.dev/docs/data-global/) that Eleventy makes available across the project.

* `en.js`: translations of template strings for English content
* `es.js`: translations of template strings for Spanish content
* `colors.js`: site color palette
* `gradients.js`: CSS gradient definitions
* `i18n.js`: sets the default language for the project (used in `.eleventy.js` for [internationalization](https://www.11ty.dev/docs/i18n/))
* `meta.js`: project metadata
* `social.js`: social media accounts

```
geojson/
  └─ city.json: MultiPolygon for city boundary
  └─ location.json: Point for physical location
```
